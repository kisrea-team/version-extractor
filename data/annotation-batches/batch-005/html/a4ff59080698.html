Version 5.23.0

Released July 28th, 2026

Release Notes

5.23 released July 28 2026

SPECS developers:
Important: The following is for SPECS 27, and not Spectacles (2024). Spectacles (2024) users should continue using Lens Studio 5.15.xx.

NEW

  • 3D Hand Mesh — A new 3D mesh that mimics the user's hand in real time for rendering, mesh effects, and attaching objects, without needing a separate hand model.

  • Custom Texture Tracking for Hands — 3D Hand Tracking and Hand Mesh can now track on custom textures such as a Media Picker texture, dual camera, or embedded video.

  • Vertex Snapping — With the Move tool active, hold V to snap the selected mesh onto a vertex of other geometry, using the same move gizmo.

  • 3D Grid Snapping — A new Scene viewport toolbar widget (or the G key) defines a grid that objects snap to while dragging gizmo handles, for placing objects set distances apart.

  • Variable Fonts — When a variable font is imported, the Font asset will automatically show its named instances and allow users to create custom styles. These styles can be selected on a Text component after assigning the variable font as the font source.

  • SVG Import — .svg files import as a Vector Composite asset.

  • Mix To Snap on Video Texture — Record an MP4 video texture's own audio into the Snap, without adding an Audio Component.

  • CRISP Compression for Gaussian Splatting Animation — Inter-frame compression giving roughly 14× smaller GSAF at ~0.04% average position error, and under 2 ms decode per frame.

  • Copy/Paste Component Properties — Copy Properties and Paste Properties in the Inspector apply one component's settings onto another component of the same type in place, without duplicating it or breaking references to it.

  • Script Update Order Panel — A project-wide view of every script grouped by update order, with inline and group-level editing, filtering, and drag-to-reorder. Also reachable from the Update Order field in the Inspector.

  • Script Debugging

    • IntelliJ and WebStorm can now attach to the JavaScript debugger, with local variables rendering correctly at breakpoints.

    • Chrome DevTools debugging is more reliable with multiple previews.

    • Lens console.* and print() output is forwarded to the debugger console.

    • Variables can be edited while the debugger is paused.

  • Perfetto Profiling enabled

IMPROVEMENTS

  • Smoother Scene viewport interaction and less stalling on large scenes.

  • Gizmo drags now keep updating when the cursor moves outside the Scene viewport while the mouse button is held.

  • Faster TypeScript compilation and .d.ts generation.

  • Dock tabs that no longer fit the tab bar now collapse into an overflow menu instead of being clipped.

  • A new SPECS Connection preference under Send to Device forces Wired Only or Wireless Only instead of choosing the transport automatically.

  • Send to Device now surfaces ADB failures, with a health check and repair step.

BUGS FIXED

  • Fixed stability and performance for big project with updated components

  • Fixed bug when dependencies were downloading with wrong name

  • Fixed bug when TypeScript not compiled when clearing TS file contents

  • Fixed bug when Masking Component not masking when changing render layer

  • Fixed crash when importing glTF files with corrupted bone data

  • Fixed crash when importing empty or truncated native library files

  • Fixed SPECS publish reporting authorization failures as network errors

  • Fixed graph pan and zoom being reset when a graph is edited on disk

System Requirements

Operating System

Windows 11 (64 bit); MacOS 12.0+

Hardware

Minimum of Intel Core i3 2.5Ghz or AMD FX 4300 2.6Ghz or Apple M1 with 8 GB RAM; Intel HD Graphics 5000 / Nvidia GeForce 760 / AMD Radeon HD 5570 or better; screen resolution of 1280x768 or higher

Please make sure that you have the latest driver for your specific graphics card installed
