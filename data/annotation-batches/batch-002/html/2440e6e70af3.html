Amie update #126

February 10, 2026

craft integration

we now integrate directly with craft! you can push meeting notes or action items directly there.

to set it up:

  1. in craft: find Imagine in the sidebar
  2. in craft: click New API Connection
  3. in craft: pick what you want to connect, easiest is: Connect All Documents
  4. in craft: copy the URL they provide you
  5. in Amie: go to Settings > Integrations
  6. in Amie: pick the matching craft integration
  7. in Amie: paste the URL into the input field and click connect

more improvements:

  • better browser call detection on macOS (now supports microsoft edge)
  • better calendar sync for resource calendars and edge cases
  • improved performance for calendar lookups
