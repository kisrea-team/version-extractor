    LibreOffice 26.2.5 (July 24, 2026) - Latest Branch

    The latest version of LibreOffice, recommended for technology enthusiasts, which contains new features and program enhancements. This version may contain a few annoying bugs which will be fixed in the next bugfix versions to come. Detailed release notes can be accessed from the link below.

    LibreOffice 26.2.5 is the fifth bugfix release of the latest line. For a list of fixed bugs compared to the previous release see the dedicated pages: RC1 / RC2.
