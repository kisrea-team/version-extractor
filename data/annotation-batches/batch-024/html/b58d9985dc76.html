    1Password CLI

    by Simon
    Download 1Password CLI

    1Password CLI 2.38.1 is now available. 🎉

    This release makes reading items with 1Password CLI faster. Commands like op read and op item get now make up to two fewer network round-trips per read. The improvement is largest on higher-latency connections, where each saved round-trip counts for more.
