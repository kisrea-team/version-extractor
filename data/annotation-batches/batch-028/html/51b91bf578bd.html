功能展示

面向 Agent 的完整工作台

聊天、流式输出、附件、MCP、Skills、Memory、Profiles、定时任务与运行时健康面板都已内置。

对话与工作流

为 Agent 工作流打造的完整聊天体验。

  • 流式对话 实时流式输出，支持多轮上下文，响应即刻可见。
  • 对话历史 完整的会话历史管理，随时回溯、继续未完的任务。
  • 附件支持 拖拽文件直接加入对话，交给 Agent 一并处理。
  • LaTeX 与 Mermaid 原生支持 LaTeX、Mermaid 等内容渲染，公式、流程图与结构化说明可直接展示。

Agent 能力

让 Agent 真正能干活的核心能力集。

  • Skills、记忆与 MCP 统一管理内置技能、长期记忆与 MCP 工具服务，Agent 所需的能力上下文集中配置。
  • Profile 切换 多套配置档位，一键切换不同工作场景。
  • 定时任务 用自然语言描述，即可创建定时调度任务。

模型与部署

兼容云端服务商与本地模型部署。

  • 云端与本地模型 原生支持火山方舟、千帆、混元、百炼、智谱、MiniMax、Kimi，以及 Ollama、vLLM、LM Studio、llama.cpp 本地部署。
  • 模型配置与切换 集中管理多家服务商的密钥与参数，随时切换。
  • 凭据与 OAuth 支持 OAuth 登录与凭据集中管理。

运行时与安全

把生产级的稳定与安全交给桌面端。

  • 托管运行时 预置 runtime，升级或修复时支持下载、更新与一键回滚。
  • 签名校验 Ed25519 签名验证，确保内核来源可信。
  • 诊断与日志 Dashboard、gateway、runtime 健康状态与日志查看，问题一目了然。

常见问题

你可能想知道

和 Web 版 / 上游有什么区别？

本项目是 Hermes Agent 的桌面端外壳，补齐原生窗口、本地进程管理、系统文件对话框、托管 runtime、运行时诊断，以及生产模式下更安全的 REST / SSE 代理层。Agent runtime 与 Dashboard 源码位于 Hermes-CN-Core，上游为 Nous Research 的 Hermes 开源项目。

我的数据安全吗？

桌面版在本地运行内核与会话状态，模型调用直连你所配置的服务商。生产模式下所有 REST、上传与 SSE 流量都经由本地 Rust 代理，集中处理鉴权，不经过第三方服务器。

支持哪些模型？

原生适配火山方舟 ARK、百度千帆、腾讯混元、阿里云百炼、智谱 GLM、MiniMax、月之暗面 Kimi、SiliconFlow、ModelScope、优云智算等模型服务商，也支持 Ollama、vLLM、LM Studio、llama.cpp 等本地部署方案，还可配置其他兼容服务。

支持 Linux 或 Intel 芯片的 Mac 吗？

支持。当前提供 Windows x64、macOS Apple Silicon、macOS Intel，以及 Linux x64 的 .deb 与 AppImage 安装包。
