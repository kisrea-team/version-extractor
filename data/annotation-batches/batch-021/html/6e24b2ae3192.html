新功能

  • 浏览器操控：MiniMax Code 现在可以在内置浏览器中连续读取页面、填写内容、上传当前任务或工作区中的文件，并自动检查操作结果。遇到发布、发送、提交等对外操作时，会在执行前再次向你确认。首次使用时，也可以在确认后从 Chrome 导入 Cookie，复用已有登录状态；导入不包含浏览历史、缓存和已保存的密码。
  • Goal 模式：你可以将复杂、耗时的任务设为 Goal，让 MiniMax Code 围绕目标持续推进。过程中可以随时查看当前状态和已用时间；任务需要补充信息或申请权限时，Agent 会在对应节点提问或发起审批；目标完成或无法继续时，也会给出明确结果。
  • 用户反馈中心：问题反馈与响应流程升级。现在可以通过左下角菜单或对话中的反馈入口提交问题，系统会自动附上当前任务、工作区、客户端版本等信息，并支持添加截图和诊断日志；如有隐私顾虑，也可以关闭日志上传。提交后，可在「我的反馈」中查看工单编号与处理状态。

​
体验优化

  • 对话文件输出优化：对话中的文件输出与交互全面升级。MiniMax Code 生成或引用的文件会以更清晰的结果形式呈现，点击即可在项目中精准定位文件、目录或对应代码行。
  • 默认快捷键：新增默认快捷键，并在设置中提供统一的快捷键管理入口。你可以搜索、修改、删除或恢复快捷键；新建任务、打开项目、搜索、切换侧边栏、打开终端和切换任务等常用操作都可以通过键盘快速完成。

MiniMax Code 2.0 正式上线

我们对 MiniMax Code 底层进行了全面重构。无论是日常对话、办公协作，还是长程复杂任务，都将有更流畅、更稳定的体验。

​
体验优化

  • 缩短新建会话到首次输出的等待时间，首 Token 的 P95/P99 尾延迟降低 90% 以上。
  • 减少对话过程中的异常中断和静默卡死；发生错误时提供更明确的状态反馈。
  • 优化会话状态和工具调用信息的保存与传递，降低会话意外丢失或执行上下文中断的情况。
  • 精简运行时依赖，改善低内存设备上的运行体验。
  • 优化 Windows 安装流程，缩短安装等待时间。
