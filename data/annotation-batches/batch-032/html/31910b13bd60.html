Visual Studio 發行歷史

本文內容

我們會定期更新 Visual Studio，為您提供新功能、效能與穩定性提升、安全更新及錯誤修正。

我們提供較舊且未受支援的 Visual Studio 版本，讓企業版和專業版客戶能靈活掌控何時採用更新。 如需詳細資訊，請參閱我們的支援原則或發行節奏文件。

Visual Studio 社群版僅在使用最新版本 Visual Studio 的 Stable 頻道支援。

安裝特定版本

如果您是企業或專業版客戶，需要install或update到 Visual Studio 的特定版本，您可以在下方表格中找到可用的啟動程式。 每個頻道都有一個單獨的版本。 通道識別碼會控制後續可透過管理員更新取得的更新。

舊版本的管理員更新套件也可從 Microsoft更新目錄取得。 這些套件會將 Visual Studio 安裝或網路佈局更新為已安裝頻道的套件版本。 關於如何建立或維護網路佈局的更多說明，可參考 Visual Studio 管理員指南 或 更新基於網路的安裝 Visual Studio 文件。

卸載 Visual Studio 以回到較早的版本

如果您想要還原到先前安裝的版本，請使用 復原功能。 復原僅允許您使用先前安裝的版本。 例如，如果您的安裝從 18.0.5 更新至 18.0.7，則復原只會將您的安裝傳回 18.0.5，而不是 18.0.6 或 18.0.1。

如果您想要還原至其他版本，您必須先 解除安裝目前的安裝 ，然後使用下列其中一個連結重新安裝您偏好的版本。 在嘗試安裝舊版 Visual Studio 之前，請參考我們的 support 政策。 Microsoft 不保證在此政策之外提供支援。

請注意，卸載 Visual Studio 不會移除獨立產品與元件，如 .NET、SQL、IIS、Visual C++ 重新發行版及 SDK。 這些可能需要手動從Windows設定中的已安裝應用程式移除。
