Parallels Desktop for Mac 26.4.0 (57513)

Parallels Desktop for Mac 26.4.0 (57513) 更新解决了整体稳定性和安全性问题，并包含以下新增功能和改进：

Windows 虚拟机

  • 已修复：导致 Windows 11 虚拟机崩溃、启动或关机后卡死，或随机关机的各种问题。
  • 已修复：RSTAB9 查看器应用在尝试查看文件时会出现黑屏。
  • 已修复：多种基于 OpenGL 的应用程序（例如 Blue Sky Plan 和 coDiagnostix）会将渲染区域显示为完全黑色。
  • 已修复：在 Windows 虚拟机中无法打开 Microsoft Outlook 中的附件。

Linux 虚拟机

  • 已修复：在使用 Xfce 桌面的 Kali Linux 虚拟机中，部分屏幕区域会变得无法响应。

macOS 虚拟机

  • 已修复：当网络接口通过桥接连接到 Wi-Fi 时，macOS Ventura 13 无法连接到互联网。

企业版

  • 新增：管理员现在可以使用 Microsoft Azure Storage blobs 分发黄金镜像，基于短效令牌确保安全性和无缝访问。
  • 新增：管理员现在可以使用prlsrvctl info --licenseCLI 命令查询 Parallels Desktop 的激活方式（SSO 或许可证密钥），从而实现与 MDM 工具的集成，以进行合规性报告。
  • 新增：声明式部署流程现提供一项选项，可在登录前应用配置包，从而使 Windows 能够注册到 Intune 并预先完成配置，用户只需使用其工作或学校帐户登录即可。
  • 改进：声明式部署流程现已针对相同设置更新了部署选项说明。

Parallels Desktop for Mac 26.3.3 (57507)

Parallels Desktop for Mac 26.3.3 (57507) 更新解决了整体稳定性与安全问题，并包含以下新增功能与改进：

Windows 虚拟机

  • 更新安全启动密钥至现有 Windows 11 虚拟机的 Microsoft 2023 证书链。

Parallels Desktop for Mac 26.3.2 (57398)

Parallels Desktop for Mac 26.3.2 (57398) 更新解決了整體穩定性和安全性問題，並包含以下新增功能與改進：

Windows 虛擬機器

  • 已修正：一項導致 Apple silicon Mac 上多個基於 OpenGL 的應用程式無法正確渲染 3D 圖形的問題，此問題會導致視窗顯示為空白或變形。受影響的應用程式（例如 coDiagnostiX、DIALux evo、Dlubal RFEM 6、Pcon Planner、PirateStorm 及 Vcarve Pro 12.5）現已能正常顯示。
  • 已修正：將 Mac 更新至 macOS 26.4 後，無法在 macOS 應用程式（例如 Microsoft Word、Microsoft Excel 及 Preview）中直接開啟來自 Windows 虛擬機的檔案。
  • 已修正：將 Mac 更新至 macOS 26.4 後，Windows 虛擬機器與 macOS 桌面之間的檔案複製與貼上功能停止運作。
  • 已修正：來自 Windows 應用程式（如 Microsoft Outlook Classic 和 Danea Domustudio Cloud Pro）的 PDF 附件無法在 Mac 的 macOS Preview 或 Adobe Acrobat 中開啟。

Parallels Desktop for Mac 26.3.1 (57396)

Parallels Desktop for Mac 26.3.1 (57396) 更新解决了整体稳定性和安全性问题，并包含以下新增功能和改进： 

通用更新

  • 已修复：在特定条件下，虚拟机将收到无效的 DNS 响应，从而影响各类应用程序。 

Windows 虚拟机

  • 已修复：将 Parallels Desktop 更新至 26.3.0 版本后，Steam 无法在 Windows 11 虚拟机中启动。 

  • 安全性：已为新建的 Windows 虚拟机更新了安全启动证书，以确保其正常运行。 

Parallels Desktop for Mac 26.3.0 (57392)

Parallels Desktop for Mac 26.3 (57392) 更新解决了整体稳定性和安全性问题，并包含以下新增功能和改进：

通用更新

  • 修复：安装助手在设置新 Windows 11 虚拟机接近尾声时可能卡住且无法完成。现已确保可靠完成。
  • 修复：续订后短时间内错误显示许可证过期警告的问题。续订后许可证状态将正确显示。
  • 改进：prlctl -i 命令现可返回更丰富的信息，包括虚拟机 IP 地址、网络限速状态以及该虚拟机是否为其他机器的克隆体。

Windows 虚拟机

  • 更新：通过微软"获取 Windows 11"提供的默认 Windows 11 映像现已更新至最新 25H2 版本。
  • 修复：Windows 11 安装可能中途卡死无法完成。
  • 修复：虚拟机在 Coherence 模式下运行时，Microsoft Excel 的下拉菜单无法展开。
  • 修复：添加 Exchange 邮箱账户后 Microsoft Outlook 经典版崩溃的问题。
  • 修复：在 Windows 11 虚拟机中安装后 Git Bash 无法启动。
  • 修复：MSYS2 安装程序在 Windows 虚拟机内崩溃且无法完成安装。
  • 修复：运行图形密集型应用程序或游戏可能导致虚拟机无响应并完全冻结 Parallels Desktop，需重启 Mac 才能恢复。
  • 修复：Windows 桌面窗口管理器不稳定导致系统崩溃或显示异常。
  • 修复：在 Coherence 模式下，窗口堆叠顺序可能错误。例如，设置为始终置顶的窗口可能被其他窗口覆盖。

Linux 虚拟机

  • 修复：在 Apple Silicon Mac 上运行于 Linux 虚拟机内的 x86 应用程序表现不稳定，需频繁重启虚拟机才能恢复正常运行。
  • 修复：Linux 虚拟机在切换网络模式（如共享模式与桥接模式）或断开/重新连接网络适配器后会丢失互联网连接。此前需重启虚拟机才能恢复连接。

macOS 虚拟机

  • 修复：在运行 macOS Tahoe 26.1 的虚拟机中无法安装 Parallels Tools。
  • 修复：当主机 Mac 更新至 macOS Tahoe 26.1 后，macOS 虚拟机无法启动。
  • 修复：加密的 macOS Ventura 虚拟机在运行 macOS Ventura 的 Mac 上启动时卡在启动界面且无法启动。
  • 修复：prlctl list 命令未在其文件夹输出中包含主目录。

企业版

  • 新增：管理员现可自定义单点登录窗口显示文本，例如指导用户使用特定格式的企业邮箱地址登录。
  • 修复：解决若干影响声明式虚拟机部署模式的问题。
  • 修复：关联虚拟机删除后，Parallels 文件夹内会残留包含 ISO 文件的临时文件夹，现已实现自动清理。

Parallels Desktop 26 Update 3 中已弃用或移除的功能

根据参与 Parallels 客户体验计划的用户统计数据，部分产品功能极少被使用或完全未被使用。为了将资源集中于高频使用的功能及进一步的改进，我们决定停止支持这些功能，或将其完全从 Parallels Desktop for Mac 中移除。

以下是即将停止支持并被移除的功能列表——这些功能不会在 26.3.0 版本中移除，而将在 Parallels Desktop for Mac 的下一个主要版本中移除：

  • Mac 与 Windows 集成：HTTP 链接的"在 Mac 中打开"功能、Safari 插件"在 Edge 中打开"、"在…上分享"菜单、"通过 Windows 邮件应用发送"功能，以及虚拟机 Dock 图标的实时截图功能。
  • 虚拟机配置与磁盘管理："释放磁盘空间"菜单、"回收"按钮及磁盘进度条、维护选项、SATA 位置选择器。
  • 显示与输入：画中画模式、Touch Bar 支持、次级/中键鼠标点击快捷键、锁定图标以阻止虚拟机配置或 Parallels Desktop 偏好设置中的 UI 更改。
  • 设备与账户：虚拟打印机设备、使用 Facebook 登录、虚拟机模板。

Parallels Desktop for Mac 26.2.2 (57373)

Parallels Desktop for Mac 26.2.2 (57373) 更新解决了整体稳定性问题，并包含以下修复与改进：

通用修复

  • 修复了在“免费系统”中新建虚拟机时，即使存在网络连接仍会显示“请将您的 Mac 连接到互联网以获取可用系统列表”提示的问题。

Windows 修复

  • 修复了日语键盘布局检测异常的问题，该问题导致日语用户出现意外输入行为。

企业版

  • 修复了声明式部署中无人值守安装无法正确配置 JIS 键盘语言和键盘设置的问题，此前需额外手动设置。

Parallels Desktop 26 for Mac 26.2.1 (57371)

Parallels Desktop for Mac 26.2.1 (57371) 更新解决了整体稳定性和安全性问题，并包含以下新增功能和改进：

Windows

  • 修复了在输入凭据后 QuickBooks Pro Plus 2024 无法正常加载的问题。
  • 修复了在Coherence模式下运行Windows 11虚拟机时，用户无法调整应用程序窗口大小的问题。
  • 修复了无法从共享下载文件夹正确启动 MSI 安装包的问题。
  • 修复了无法在 Mac 上访问 Windows 11 虚拟机已共享文件，反之亦然的问题。

Parallels Desktop for Mac 26.2.1 Enterprise Edition

  • 修复了使用声明式部署方法部署虚拟机时无法正常应用策略的问题。

  • 修复了用户即使部署策略限制其仅能创建一台虚拟机，仍可添加第二台Windows虚拟机的问题。

Parallels Desktop 26 for Mac 26.2.0 (57363)

Parallels Desktop for Mac 26.2.0 (57363) 更新解决了整体稳定性和安全性问题，并包含以下新增功能和改进：

常用

  • 修复了 导致 用户在Apple silicon Mac上创建新虚拟机时无法更改虚拟硬盘大小的错误。 Windows · 添加对从Windows虚拟机向Mac安全转发受限键盘输入的支持，使Dragon Medical One可通过宏指令控制Epic Hyperspace。
  • 修复了在Windows 11系统上运行《吸血鬼》游戏5至10 分钟后断开连接的问题。
  • 修复了在Windows 11 25H2虚拟机切换至Coherence模式时，MS Office 365窗口消失的问题。
  • 修复了将Parallels Desktop添加至主机Mac登录项目时错误触发器"旧版Parallels Desktop正在运行"提示的问题。
  • 修复了 将 的Windows 11虚拟机切换至Coherence模式时GPU使用情况骤升的问题。
  • 修复了Coherence模式下Windows开始菜单无法显示的问题，其中Coherence模式下Windows开始菜单无法显示。
  • 修复了macOS Dock中Windows应用文件夹的多种问题。

Linux

  • 修复从Linux虚拟机复制文本粘贴到MAC时出现长时间延迟的问题。
  • 修复了断开连接后Mac重启后Linux虚拟机无法访问互联网的问题。
  • 修复了启用Smartguard快照时， 阻碍 时间同步功能的问题。
  • 修复了 Linux 版 Parallels Tools 与 Debian 13 之间的兼容性问题。

Parallels Desktop for Mac 26.2.0 Enterprise Edition

  • 引入声明式部署：基于微软最新标准企业版或教育版ISO镜像分发黄金镜像的新方案，支持便捷的OOBE跳过流程和直观的Intune注册。详情请参阅此处。
  • 将控制主机 Mac 与虚拟机间复制粘贴同步的策略功能重命名为拖放同步控制，以反映其新增的拖放同步管理功能。
  • 修复了正在应用设置时（即使未包含外部设备连接限制）导致 Parallels 虚拟机 USB 设备菜单消失的问题。
  • 修复了当"隔离虚拟机与Mac > 控制剪贴板同步"策略设置为"仅限Mac到客体操作系统"时，从虚拟机拖拽文件至Mac会导致文件消失的问题。

Parallels Desktop 26 for Mac 26.1.2 (57293)

此更新针对 Parallels Desktop 26 for Mac 26.1.2 (57293) 版本，主要解决整体稳定性和性能问题。

Parallels Desktop 26 for Mac 26.1.1 (57288)

Parallels Desktop 26 for Mac 26.1.1 (57288) 的此次更新解决了整体稳定性与性能方面的问题。

Parallels Desktop 26 for Mac 26.1.0 (57287)

Parallels Desktop for Mac 26.1.0 (57287) 更新解决了整体稳定性与安全性方面的问题，同时添加了以下新功能，并做出了一些改进：

Windows

  • 修复了 Norton 360 安全软件执行定期智能扫描时导致 Windows 11 虚拟机出现蓝屏死机的问题。
  • 修复了 Bluebeam Revu 软件用户在 Coherence 模式下无法登录的问题。

Linux

  • 推出全新无人驾驶版本的Parallels Tools for Linux，旨在最大限度减少安装和内核兼容性问题。
  • 新增了几个经过更新的 Linux 发行版（包括 Ubuntu 24.04.3、Kali 2025.2 和 Debian 12.11），可在搭载 Apple 芯片的 Mac 上快速安装。
  • 修复了导致运行 Ubuntu 25.04 的虚拟机无法与 Mac 共享连接驱动器的问题。
  • 修复了导致共享文件夹在运行 Fedora 41 的虚拟机上显示为空的问题。
  • 修复了重启 Mac 后运行 Debian 12 的虚拟机无法连接到网络的问题。

Parallels Desktop for Mac 26.1.0 Enterprise Edition

  • 引入 Parallels Tools for Linux 新的无驱动版本，旨在减少安装与内核兼容问题。注意：此升级适用于 Linux 内核 5.10 或更新版本。
  • 新增了通过 Parallels Management Portal 控制虚拟机设置的功能。点击此处了解详情。
  • 新增了在单应用模式下通过 Single Sign On (SSO) 激活 Parallels Desktop 的功能。注意：此功能需要 Parallels Mass Deployment 软件包版本 26.1.0 或更新版本。
  • 改进了下载黄金镜像时对 SharePoint 链接的处理能力。

Parallels Desktop 26 for Mac 26.0.1 (57243)

Parallels Desktop 26 for Mac 26.0.1 (57243) 的此次更新解决了整体稳定性与性能方面的问题。

Parallels Desktop 26 for Mac 26.0.0 (57238)

全新 Parallels Desktop 主要版本 26.0.0（构建版本 57238）包含多项底层升级，旨在更好地支持最新版 macOS。本次版本号从 Parallels Desktop 20 直接跃升至 Parallels Desktop 26，以便与 Apple 新一代 macOS 版本号体系保持同步。

本版本提供了以下功能改进：

所有版本的 Parallels Desktop 26 for Mac

  • 全面兼容 macOS Tahoe 26。

Parallels Desktop 26 支持即将发布的 macOS Tahoe 26，后者既可以作为 Mac 上的主操作系统，也可以在虚拟机中运行，因此您可以在新操作系统可用时升级 Mac 计算机。

外观与风格

  • 在运行 macOS Tahoe 26 的 Mac 上全面更新了图标设计。

在 Mac 上运行 Windows

  • 让 Windows 系统能够精准评估 Mac 上的可用磁盘空间，避免因安装过大的 Windows 软件影响 Mac 的响应能力。
  • 改善了 Coherence 模式下 Windows 全屏应用的行为，让您的 Mac 能够正常进入睡眠模式。
  • 修复了 Windows 11 虚拟机中《女神异闻录 5：皇家版》启动时崩溃的问题。

在 Mac 上运行 Linux

  • Apple 芯片版 Mac：添加了对 Ubuntu 24.04.2、Fedora 42、Debian 12.6 和 Kali 2024.2 等新 Linux 发行版的开箱即用支持。
  • Intel Mac：添加了对 Ubuntu 24.04、Fedora 40、Debian 12.6 和 Mint 21.3 等新 Linux 发行版的开箱即用支持。
  • 修复了在 Intel Mac 上运行 CentOS 10 时，无法正确安装 Parallels Tools for Linux 的问题。

Parallels Desktop 26 for Mac 商业版与企业版

  • 添加了系统管理员通过 Jamf 脚本管理和监控虚拟机软件更新的功能。
  • 为通过黄金镜像部署的虚拟机重新生成了唯一标识符，确保 Intune 注册流程顺畅无阻。

Parallels Desktop 26 中弃用或删除的功能

根据参与 Parallels 客户体验计划的用户统计，一些产品功能很少使用或根本没有使用。我们已经决定停止支持这些功能，或者将它们从 Parallels Desktop 中完全删除，转而专注于经常使用的功能和进一步增强功能。

以下是 Parallels Desktop for Mac 26 已移除且不再支持的功能列表。

  • 在运行 macOS Monterey 12 的 Mac 上安装 Parallels Desktop。
  • 共享蓝牙功能。连接到 Mac 的蓝牙设备(如键盘、鼠标或游戏控制器)将继续在虚拟机中正常工作。注意：要将蓝牙设备直接连接到虚拟机，请考虑使用 USB 蓝牙加密狗。
  • USB 和网络 kexts（内核扩展）。此停用会影响使用 Parallels 虚拟机管理程序在 Intel Mac 上运行的虚拟机；此类虚拟机将继续在无内核扩展模式下支持 USB 和网络适配器。
  • 激活延迟。
  • 在部署包设置中指定自定义更新服务器。
  • 在 Parallels Desktop 控制中心与 macOS Finder 之间同步虚拟机颜色标签。
  • 使用 Parallels Desktop 菜单在 Windows 虚拟机中安装 Parallels Toolbox for Windows 的选项。
