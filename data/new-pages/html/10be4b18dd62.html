Jul 31, 2026

Claude Opus 5, direct Figma inspection, and composer prompt history

What's new

  • Claude Opus 5 is available in the model picker, with an Opus 5 Fast tier for faster responses.
  • Connect a Figma file and v0 reads its structure and styles directly while building, instead of the older import-and-screenshot step, and v0 loads the Figma skill automatically when a message includes a Figma link.
  • Recall earlier prompts with Up and Down in the composer, including their attachments and attached skills.
  • Keyboard shortcuts for the prompt queue: Cmd or Ctrl and Enter sends and interrupts the active response, and Cmd or Ctrl with Up and Down step through queued prompts.
  • URLs typed or pasted into the composer, and shown in sent messages, are highlighted inline with the site's favicon.
  • When a generated app needs AI features, v0 decides how to build them from the app's requirements instead of pausing to ask you.

Bug fixes

  • Figma connections whose stored credentials could no longer be decrypted are cleared so you are prompted to reconnect, and Figma links without the www subdomain are accepted.
  • Stopping a response or interrupting a queued prompt takes effect immediately, and deleting a queued prompt while editing it no longer leaves it stuck and reappearing after a reload.
  • Download ZIP no longer returns an empty archive for VM chats, starting a chat from a ZIP keeps dotfiles such as .gitignore, and large ZIP and branch operations no longer time out.
  • Duplicating a Git-backed chat produces a working copy instead of one that fails to render.
  • Open in v0 and Git deployment lookups prompt for SAML re-authentication instead of getting stuck or failing with a generic error.
  • The preview keeps its loading state until the iframe paints, removing a brief black flash after a VM starts.
  • On phones, sending the first message keeps you on the chat instead of jumping to Preview.
  • The sidebar no longer flashes on load on narrow screens, and a chat row's relative time matches its hover card.
  • The chat header no longer overflows on smaller screens.
  • A failed checkout shows a retry instead of a stuck loading state, and layout no longer shifts on the checkout page as it loads.
  • Upgrading between plans no longer gets stuck on a previous plan's selection.
  • The out-of-credits notice clears once the chat's scope has credits again.
  • Fixed a stuck file-drop overlay in the composer and refined attachment chips.

Misc.

  • The sidebar hover card previews how a turn ended, such as its closing summary or the question it is waiting on, and the in-progress status reads "v0 is working".
  • The queued-prompts panel starts expanded.
  • The free-tier all-model-access bar fills over time instead of draining.
  • The free Fix with v0 daily limit is 10 per day.
  • The generation-complete sound is quieter.
  • Long prompt errors show their full text on hover.
  • Picking a model returns focus to the composer.
  • Expired subscribers see a clearer message that using purchased credits requires an active subscription.
  • The credit-exhaustion message reads "You are out of credits".
Jul 21, 2026

Slash commands, the Shopify integration, and a Snowflake reliability pass

What's new

  • Type / in the composer to open a slash-command menu and attach a skill without leaving the keyboard; it live-filters as you type, including remote skills.sh search.
  • The Shopify integration is available to everyone: connect a Shopify store and v0 builds a storefront that reads live products, prices, and inventory through the Shopify Storefront and Admin APIs.
  • Attached skills appear as inline chips in the composer, with the same draft persistence, undo/redo, and drag-to-reorder as file attachments.
  • v0 plays a sound when it finishes responding while the window is not focused, controlled by a Sound Notifications toggle in Settings that is on by default.
  • Settings → Integrations shows your GitHub connection status with Connect, Reconnect, and Manage actions.
  • Snowflake detects when a chat's code has changed since its last deployment and offers a re-deploy, and it steers generations to your team's connected Snowflake account instead of mock data.
  • Request access to a private chat in your team directly from the chat, and save any chat you can access to your favorites, including shared chats.
  • VM-backed chats can publish even when the chat has no deployable blocks.
  • Generated chat titles and project names focus on product identity instead of implementation details.
  • The first-publish wizard is simpler: visibility comes before domains, the final action reads Publish, and project creation stays on a stable loading step until it is ready.
  • Redesigned the account dropdown and flattened integration management in Settings into a single Manage menu per integration.
  • The Import Design System panel opens as a full-height side panel with inline Add buttons, and pasted files attach directly to the drawer.

Bug fixes

  • Snowflake: fixed OAuth on preview deployments, connect and reauthentication prompt flicker, connection modals stuck on infinite spinners, and credential refresh inside previews. Connections are preserved when forking a chat, New Chat works on projects that deploy to Snowflake instead of Vercel, integration settings are visible to team members with the Contributor role, and shared-chat viewers without their own connection see a Connect prompt instead of a crash.
  • Chats started from a Git repository get a generated title instead of the working branch name, and generated branch names stay stable after a pull request is created.
  • Agent auto-pushes retry after rebasing when a push is rejected as non-fast-forward, and chats stranded by an interrupted post-merge Git rotation recover on their own.
  • Creating a GitHub repository from a team-scoped chat uses the correct Vercel team instead of failing with a SAML error.
  • Duplicating a chat no longer produces a broken copy that fails its first build.
  • Environment variables added in v0 reach published apps on teams that enforce Sensitive Environment Variables.
  • The publish popover shows the subdomain you chose while the deployment builds instead of the raw deployment URL.
  • Fixed several preview glitches: a duplicate loading screen on new previews, the v0 logo briefly expanding to fill the preview, previews not appearing until after the first generation, broken v0.app iframe previews, and a false deployment error before publish metadata loads.
  • Returning to an already-visited chat from the sidebar no longer flashes the loading skeleton.
  • Typed prompts survive clarifying questions, permission approvals, and queued submissions instead of being cleared.
  • The stop button is visibly disabled during the send window before the response starts streaming.
  • Command-Left and Command-Right move to the start and end of composer lines that contain attachments.
  • A stray YubiKey touch no longer submits its one-time password as a chat message, and large encoded message parts no longer render as raw text.
  • Connecting Figma works for team members without Marketplace integration permissions, and free-plan users see the upgrade dialog instead of a generic error.
  • Design systems: personal-scope imports save to your own memory, the selector resets when you switch scopes, applying a starter preserves Git history, and ZIP asset downloads work without CORS errors.
  • Expired team sessions start SAML re-authentication automatically, SAML-limited sessions recover into the existing dialog, and a force-sign-out race is resolved.
  • The Add button in Domains settings links to the correct Vercel project.
  • Canceled plans show the subscription end date in the credit balance, and checkout maps actionable payment failures to clear messages.
  • Organizations no longer need to set a spend limit for chats to work.
  • Hardened authentication against a magic-link login CSRF and session-fixation issue, open redirects after login and logout, and OAuth callbacks attaching credentials to a different account; free-plan alias-prefix and GitHub-organization repository restrictions are enforced server-side.

Misc.

  • The Team plan is renamed to Plus.
  • Enterprise Managed Users are surfaced in the web UI, and their profiles are always private.
  • Provider text streams in steady small deltas instead of arriving in uneven bursts.
  • Demo links accept a loadingBackground parameter to set the background shown while the generated app loads.
  • Personal upgrades default to Premium.
Jul 7, 2026

Grouped tool approvals, richer MCP tools, and team deployment policies

What's new

  • Tool permission approvals for MCP and bash are grouped into one panel above the composer, so resolving one approval no longer advances the chat before you handle the rest.
  • The v0 MCP server adds a listMessages tool to read a chat's history and a resolveTask tool to answer plan approvals, questions, permission requests, and integration prompts, and it now returns scope-aware chat URLs.
  • Pasted attachment pills in the composer can be dragged to reorder.
  • v0's deploy button and GitHub import respect your team's Vercel deployment policies, hiding disallowed repositories and blocking production deploys your team forbids.
  • v0 no longer blocks pushing to GitHub repositories that contain GitHub Actions workflow files.
  • Design Systems: set a team default (including Design Systems 2.0 skills and built-in examples) and choose team or personal scope when saving a design system from the save card.
  • Team members with v0 edit access can manage team skills and memories without a Vercel write role, and the Restrict Memories and Skills setting is available on any paid team plan instead of Enterprise only.
  • Preview loading is smoother: the empty or previous preview shows immediately while the VM starts in the background, with a subtle progress line and no loading status pills.
  • The project menu mirrors the chat menu's actions, and a new keyboard shortcut (Cmd+. or Ctrl+.) opens Settings.
  • The publish button shows a tooltip explaining why it is disabled, such as waiting for v0 to finish responding.
  • v0 builds chat interfaces with shadcn/ui chat primitives and the latest AI SDK instead of the deprecated AI Elements.
  • The Platform API can attach memory and project skills when creating a chat or sending a message, and its message schema returns the agent's clarifying question, requested integrations, and permission details for tasks that need user input.

Bug fixes

  • Fixed GitHub connect and SSO reauthentication, so creating a repo or connecting GitHub no longer returns a bad request or opens the wrong Vercel team SSO dialog.
  • Auto-push for team-owned chats no longer fails silently, so edits reliably reach the GitHub working branch.
  • Connecting an MCP server from the integrations card no longer spins the agent into an auto-resume loop that Stop could not break.
  • Opening the command menu and then navigating into a chat no longer crashes the app.
  • A preview stuck on a dead or expired sandbox now recovers automatically instead of staying broken.
  • Hardened the screenshot service, frame proxy, and chat hook delivery against DNS-rebinding SSRF.

Misc.

  • Preview sandboxes can run for up to 24 hours.
  • Faster VM preview startup and Vercel deploys, trimming several seconds of setup.
  • Navigating to the new-chat home is instant.
  • Signed-out users get a higher preview sandbox limit of 240 per hour, and hitting it prompts sign up or sign in.
  • Added a Shopify integration docs page and fixed the docs mobile menu and several broken documentation links.

Deprecations

  • Invite & earn, the referral credit program, is being discontinued on July 15, 2026. Referral links stop earning new credits after that date, and credits you have already earned stay in your account.
