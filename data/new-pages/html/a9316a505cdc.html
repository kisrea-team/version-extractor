Release notes for Enpass Windows (Website Version)

Version 6.12.5 (x64.2659 / arm64.2661)

Release Date: July 23, 2026

This update ensures business administrators can manage vault access for all members of Google Workspace Shared Drives.

Vault sharing now supports Google Shared Drives with more than 100 members
The “Manage Access” screen for a vault in the Share Center now displays the complete list of members for any Google Workspace Shared Drive, regardless of the group size. Previously, the list was limited to the first 100 members, which prevented administrators from granting vault access to everyone in larger organizations.

This version also includes other minor bug fixes and improvements.

Version 6.12.4 (x64.2635 / arm64.2637)

Release Date: July 06, 2026

This update introduces a re-engineered Security Score to prioritize critical risks; it also optimizes Wi-Fi Sync connectivity and ensures a better experience when managing notes and icons.

Improvements

  • A More Meaningful Security Score
    You can now see a more accurate representation of your vault’s health through an enhanced scoring engine. This means the dashboard now prioritizes critical issues, like compromised passwords, and rewards the use of phishing-resistant factors like Passkeys.
  • Optimized Wi-Fi Sync discovery
    The Wi-Fi Sync server now prioritizes active Ethernet and Wi-Fi connections while filtering out virtual network addresses from software like VirtualBox. This ensures your devices find and connect to each other reliably during synchronization.

Bug Fixes

  • Unlimited Note length
    The Notes field now supports more than 20,000 characters without truncating your data. Previously, saving an item with a very long note would silently remove content exceeding the character limit.
  • Consistent Note appearance
    The Notes field now uses a consistent background color (hex code #FFF8B9) across both light and dark themes. This replaces the bright yellow background that previously appeared in dark mode, ensuring the interface remains easy on the eyes.
  • Stable Note scrolling
    The Notes section now maintains its scroll position when a background sync occurs. Previously, the view would automatically jump to the bottom of the note whenever the app synchronized.
  • Improved custom icon quality
    Custom icons now render clearly in the interface. Previously, some user-uploaded icons appeared pixelated even when provided at the correct 200×200 pixel resolution.
  • Windows Server 2016 compatibility
    Enpass now launches correctly on Windows Server 2016 systems. Previously, a compatibility issue related to font rendering prevented the app from opening on this specific operating system version.

For Business Users

  • Vault connection clarity
    The vault settings page now displays the specific service name and icon for SharePoint, Microsoft Teams, and Google Shared Drives. Previously, these business-specific vaults were labeled generically, making it difficult to distinguish between different storage locations.
  • Refined Google Workspace permissions
    The Manage Access page for Google Workspace vaults now only displays members of the Shared Drive who also have explicit access to the vault folder. Previously, it could show users who had folder-level access but were not members of the shared drive.

This version also includes other minor bug fixes and improvements.

Version 6.12.3 (x64.2605 / arm64.2607)

Release Date: June 23, 2026

Autofill while locked The desktop app now serves cached autofill items metadata to the browser extension even when locked and requires to unlock Enpass when an item is selected for filling. Requires Enpass browser Extension v6.11.14

Added support for Conditional Passkey Sign-in and Enrollment The desktop app now supports the underlying passkey handling required for conditional passkey sign-in and password-to-passkey enrollment flows initiated from the browser extension.

Passkey Management Links Enpass now reads website-provided well-known passkey URLs to surface the right actions at the right time. When a site declares where users can enroll or manage their passkeys, Enpass shows the appropriate buttons directly in the app.

Improved SharePoint vault sharing by increasing the supported member limit for shared SharePoint sites from 1,000 to 5,000 users, enabling vault sharing with larger groups.

Version 6.12.2 (x64.2551 / arm64.2555)

Release Date: June 04, 2026

We hope you’re enjoying the new Enpass UI! Based on your feedback, we’ve fixed several issues in this release, and more fixes are on the way. If you’re facing any issues, feel free to reach out to us at support@enpass.io.

This release brings smoother navigation and several reliability, display, and localization fixes.

  • Activation works reliably after reconnecting to the internet
    The activation process now recovers smoothly when your internet connection is restored after an initial network error. Previously, an SSL error could persist even after connectivity was back, requiring a restart. You can now simply retry and continue without restarting Enpass.
  • Notes field now stays expanded reliably
    The Notes field now stays expanded as expected. Once you expand the Notes field for any item, it remains expanded across all items until you manually collapse it or restart the app. Previously, the Notes field could collapse unexpectedly.
  • Notes text is now readable in Dark theme
    Text entered in the Notes field now displays in the correct color when using the Dark theme. Previously, the text could appear in black on a dark background, making it hard to read.
  • Security score now displays correctly on launch
    The security score on the Home dashboard now shows the correct value as soon as the app launches. Previously, it could display an incorrect score until you navigated away and returned.
  • Item editing options are now translated
    The item editing options (such as Attachment, Section, and Add Field) now display in your chosen language. Previously, these options appeared in English even when using a different language like Portuguese.
  • Keyboard shortcut now copies the right password
    The keyboard shortcut for copying passwords in the Enpass Assistant now correctly copies the password of the item shown in search results. Previously, it could copy the password of a previously selected item instead.
  • Importing from Sticky Password now preserves special characters correctly
    Importing data from Sticky Password now correctly handles umlauts and other non-ASCII characters (such as ä, ö, ü, ß, and é). Previously, these characters could appear garbled after import. Your imported data now displays exactly as it should.
  • Copy passwords directly from Enpass Assistant
    You can now copy a password directly from the Enpass Assistant’s password generator. This option was removed in a previous update, is now restored.
  • Minor bug fixes and improvements

For Business Users

  • Quickly access your vault storage location
    Business users can now open the storage location of their shared vaults directly from the Sharing Center, available for OneDrive, Teams, and SharePoint Sites vaults.

Version 6.12.1 (x64.2417 / arm64.2417)

Release Date: May 14, 2026

Enpass has been redesigned with a modern interface, cleaner layouts, and streamlined workflows. This update builds on that foundation with fixes and stability improvements based on feedback from our beta testers.

Here’s what’s been fixed:

  • Fixed an issue where the Enpass browser extension was not detected by the latest version of Microsoft Edge.
  • Enpass now runs smoothly when unlocking the app, launching from the system tray, and quitting.
  • Minor bug fixes and improvements.

If you run into any issues, reach out to us at support@enpass.io.

Version 6.12.0 (x64.2413 / arm64.2411)

Release Date: May 11, 2026

What’s New

A Fresh New Look. The Same Enpass You Trust.

Enpass has been redesigned from the ground up with a modern, polished interface, which includes cleaner layouts, streamlined workflows, and refined visuals across every screen. Plus, Enpass is now a native 64-bit and ARM64 app, bringing faster performance and improved memory usage. Everything you know and rely on works exactly the same, it just looks and feels a whole lot better.

 Here’s what you’ll notice:

  • Modern design throughout — Cleaner layouts, improved spacing, and refined icons across every screen including the sidebar, item lists, item details, editing, autofill, sharing, password generator, and lock screen.
  • Redesigned settings — Settings have a new, spacious layout that’s less cluttered and easier to read, so configuring Enpass feels effortless.
  • Streamlined workflows — Common tasks like adding items and importing data now take fewer steps and are more organized, so you can get things done faster.
  • Updated visual elements — Buttons, icons, typography, and interactive elements have been refined for a cleaner, more intuitive experience.
  • Refreshed Share Center — For Business users, you can now manage all your vault sharing in one space, and update access rights on the spot.
